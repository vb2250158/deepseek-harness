# Agent Note: 在 0.2 运行时升级中保留本机行为

Status: implemented

[English](2026-10-04-local-runtime-upgrade.md) | 中文

## 问题

本机运行时包含上游版本尚未提供的修复与界面行为。不保留改动就替换源码检出会丢失已有行为；保留旧接口又会阻止当前插件加载。

## 决策

本机源码运行时在采用上游新接口时，保留共享 HMR 连接、目标编辑、环境凭据选择、完全访问工具许可、准备失败后的后续任务，以及旧版 Session 迁移。客户端图标使用 Regular 导出，HMR 读取当前事件路由，准备失败时仅已接收的提示进入持久历史。

第三方包要求相同的 0.2 运行时，并从 main 分支可达的固定提交安装。运行时依赖由当前源码检出提供。设置迁入 profile 配置，原设置文档作为已导入的前代文件保留。已提交的 Session 世代保持不可变。

## 恢复

替换前备份原源码改动、主目录文件、profile 清单及插件仓库提交。本机源码改动仅保存在本机，不发布到上游仓库。

仅更新 lockfile 的插件操作验证指定包，并将已安装内容检查和 bundle 激活延后到实际安装。这使兼容更新能替换旧模块，同时保留实际安装对不兼容内容的拒绝。

## 考虑过的替代方案

丢弃本机改动会失去已有修复。保留旧运行时则无法安装依赖当前公共 API 的插件。

## 后果

其他电脑需要累计补丁来取得本机修改，上游接口变化时必须复核补丁。官方检出保留上游历史，共享插件仍可从各自的固定提交独立安装。
