# Agent Note：Models 编辑器支持替换启动环境密钥

Status: implemented

[English](2026-09-11-models-editor-launch-environment-key-override.md) | 中文

## 问题

Models 编辑器在当前凭据来自启动环境时禁用了 API 密钥输入。该来源按设计是只读且优先级高于凭据文件，但禁用控件让用户无法在产品内替换提供方密钥。

## 决定

用户为启动环境密钥输入替代值时，页面使用页面管理的 `<ROUTE>_API_KEY_LOCAL` 凭据引用。编辑器先把 `apiKeyEnv` 更新为该引用，再保存密钥，因此保留现有凭据优先级，同时让替代值生效。页面把这两个派生引用都视为自己管理的凭据并在删除时清理；启动环境密钥始终不受影响。

## 考虑过的替代方案

**允许写入原有引用。** 启动环境仍会覆盖它，保存操作看似成功但当前使用的密钥不会改变。

**修改凭据优先级。** 这会削弱启动器明确表达的本次运行覆盖，并改变所有凭据消费者的行为。

**要求用户重启并清除环境变量。** 这会把用户留在产品之外，也无法解决当前会话中的密钥替换。

## 影响

编辑器继续遵守凭据服务关于启动环境只读的语义。替代值会给提供方 profile 增加一个确定性的本地引用，并且密钥仍只通过 `credentials.set` 写入；profile 修改前，启动环境密钥仍可用。删除页面管理的替代值时会清除本地凭据；删除提供方不会删除启动环境中的值。

## 测试

Models 组件测试验证环境密钥可编辑、保存时写入 `apiKeyEnv: <ROUTE>_API_KEY_LOCAL`，并把替代值存入本地引用。Models 定向测试文件和仓库类型检查均通过。
